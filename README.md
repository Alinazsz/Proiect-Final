# Proiect Final – React App

A simple React application built as part of my final project.  
The project includes routing, reusable components, custom hooks, state management, and a clean UI structure.

---

## Features

- Search functionality  
- Dynamic pages with React Router  
- Custom `useFetch` hook  
- Favorites system (local state + localStorage)  
- Clean and organised folder structure  
- Simple state management using React hooks  

---

## Technologies

- React  
- React Router  
- JavaScript (ES6+)  
- CSS
